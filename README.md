# 🏫 ระบบเว็บไซต์สำนักงานโรงเรียนบ้านหนองหว้า (ระบบประมวลผล PHP & MySQL)

ยินดีต้อนรับเข้าสู่อภิสิทธิ์โครงสร้างรหัสพัฒนาคุณภาพสูงสำหรับ **โรงเรียนบ้านหนองหว้า** (อัตลักษณ์ ชมพู-ขาว) พัฒนาขึ้นในรูปแบบภาษา **PHP 8+** และการเชื่อมต่อความปลอดภัยระดับสูงผ่าน **MySQL PDO** พร้อมระบบทำฐานข้อมูลให้โดยอัตโนมัติ (Database Auto-Migration Mechanics) 

โค้ดทั้งหมดนี้พร้อมส่งออก (Export) ผ่านการกดเชื่อมต่อ GitHub และใช้งานร่วมกับระบบอัตโนมัติของเซิร์ฟเวอร์โรงเรียน (DirectAdmin, cPanel หรือ Apache Web Hosting) ได้ทันที!

## 📂 โครงสร้างไพล์ภาษา PHP ทั้งหมดที่พร้อมใช้งานในระบบ
ไฟล์ PHP หลักทั้งหมดถูกสร้างเสร็จเรียบร้อยและปรากฏอยู่ในรากของ File Explorer ของคุณ โดยมีหน้าที่ของแต่ละส่วนดังนี้:

1. **`config.php`** 
   - ⚙️ **หัวใจหลักของระบบ**: รวมศูนย์เชื่อมต่อฐานข้อมูล PDO ป้อนรหัสภาษา UTF-8 เต็มระบบ
   - 🛡️ **ระบบความปลอดภัยหลัก**: กรองช่องโหว่อย่างปลอดภัยสูงสุด (SQL Injection Prevention & XSS Filtering)
   - 🔄 **ตัวจัดการฐานข้อมูลอัตโนมัติ (Auto-Migration)**: ทำการตรวจสอบฐานข้อมูลและสร้างตารางต่างๆ ทันทีในการเปิดรันครั้งแรก (First-run Autoinstall) และตรวจสอบคอลัมน์ใหม่ หากมีความถี่การใช้งานตารางเพิ่ม จะขยายตารางเพิ่มให้อัตโนมัติ (Self-Healing Columns Alteration)
   
2. **`index.php`**
   - 🌸 **หน้าพอร์ทัลหลักสีชมพู-ขาว**: หน้าตึกพอร์ทัลต้อนรับผู้ปกครองและประชาชน พัฒนาแบบเบาหวิวด้วย Tailwind CSS Play CDN และไอคอนโมเดิร์น Lucide Icons ไม่ต้องทำ Node compilation หรือใช้ซอฟต์แวร์จัดพิลท์เพิ่มเติมบนเซิร์ฟเวอร์จริง
   - 📊 **สถิติและข่าวสาร**: ดึงแบนเนอร์ประชาสัมพันธ์, ตัวกรองฝ่ายงานกลุ่มสาระครู, จำแนกสัดส่วนนักเรียนชายหญิง และนำเสนอยอดผู้เข้าชมทั้งหมดที่ป้อนอัปเดตลงเซสชัน MySQL

3. **`login.php`**
   - 🔐 **หน้าเข้าสู่ระบบความปลอดภัยสูง**: ป้องกันการแอบมองหน้าจอ ฟอร์มสวยงามกรองสีชมพูขาว และเข้ารหัสความลับแอดมินด้วยกรรมวิธี Bcrypt (`password_verify`) ป้องกันฟิชชิงและการขโมยสิทธิข้อมูล

4. **`admin.php`**
   - 🏢 **ระบบแอดมินบอร์ด (หลังบ้าน)**: ตัวเลือกการเพิ่มกระดานข่าว ขอบเขตสำคัญสำหรับเพิ่มข่าวด่วนปักหมุดข่าววิกฤติ, เพิ่มไฟล์แผนงานจัดซื้อจัดจ้างประดับคลัง และบันทึกบุคลากรวิทยฐานะเข้าทำเนียบลำดับเรียงรายคลาส

5. **`download_file.php`**
   - 📥 **บันทึกกิจกรรมดาวน์โหลด**: ตรวจจับความเคลื่อนไหวการเข้าสิทธิไฟล์เอกสารราชการ เมื่อมีผู้ใช้งานคลิกดาวน์โหลด ระบบจะทำการบันทึกบวกหนึ่งยอดเข้าชมและสแกนดาวน์โหลดลง MySQL และนำทางดาวน์โหลดไปที่อยู่ไฟล์ปลายทางอย่างลื่นไหล

## 🛠️ วิธีการเชื่อมต่อและอัปโหลดไปยัง Web Server โรงเรียน
ตามวิธีที่ท่านแจ้งว่าใช้งานร่วมกับการเชื่อมต่อ GitHub อัตโนมัติ:

1. **ลำดับทางเข้าใช้งาน (Directory Ingress)**:
   - โดยปกติ เว็บเซิร์ฟเวอร์แบบส่วนตัว (Apache/NGINX) บน Linux Web Hosting จะจัดให้ **`index.php`** ทำงานก่อน `index.html` เสมอ
   - ดังนั้น เมื่อทำการผลักรหัสนำส่ง (Push) เข้า GitHub และ Web Server ดึงรหัสไปวาง (Deploy) หน้าเว็บจะเปลี่ยนเป็นระบบพอร์ทัลสีชมพู-ขาว และใช้ฐานข้อมูลใหม่จากไฟล์ PHP เหล่านี้ทันที

2. **การตั้งค่าชื่อเชื่อม MySQL บัญชีโรงเรียนจริง**:
   - ท่านสามารถปรับแก้ข้อมูลตัวแปรการเชื่อมฐานข้อมูลอย่างปลอดภัยได้ที่ไฟล์ **`config.php`** ขอบเขตตอนต้นบรรทัดที่ 16-19:
     ```php
     define('DB_HOST', 'localhost'); // ที่อยู่ MySQL Host (ทั่วไปคือ localhost)
     define('DB_USER', 'root');      // ชื่อผู้ใช้งานฐานข้อมูลโรงเรียน
     define('DB_PASS', '');          // รหัสผ่านเข้าฐานข้อมูล
     define('DB_NAME', 'bannongwa_db'); // ชื่อฐานข้อมูลโรงเรียนที่ประสงค์ใช้งาน
     ```

3. **ระบบอัปเดตสคริปต์อัตโนมัติ**:
   - ท่านไม่จำเป็นต้องนำเข้าไฟล์ `.sql` ใดๆ เข้าสู่ phpMyAdmin 
   - ระบบ **`config.php`** จะวิเคราะห์โครงสร้าง ทำการตรวจสอบคำสั่ง `CREATE TABLE` และ `ALTER TABLE ADD COLUMN` เพื่อสร้างคอลัมน์และตาราง และแถมข้อมูลตั้งต้นผู้บริหาร ข่าวสาร สถิตินักเรียน และเอกสารครูให้ท่านโดยอัตโนมัติทันทีที่มีการเปิดโหลดหน้าจอครั้งแรก!
